# tabularis MCP Server

## What is tabularis?

tabularis is a production-ready Model Context Protocol (MCP) server with 4,802 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install TabularisDB/tabularis

# Or manual
git clone https://github.com/TabularisDB/tabularis.git
cd tabularis
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
