# ros-mcp-server MCP Server

## What is ros-mcp-server?

ros-mcp-server is a production-ready Model Context Protocol (MCP) server with 1,436 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install robotmcp/ros-mcp-server

# Or manual
git clone https://github.com/robotmcp/ros-mcp-server.git
cd ros-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
