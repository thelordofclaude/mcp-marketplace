# vexa MCP Server

## What is vexa?

vexa is a production-ready Model Context Protocol (MCP) server with 2,755 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install Vexa-ai/vexa

git clone https://github.com/Vexa-ai/vexa.git
```
