# resume-tailor-mcp MCP Server

## What is resume-tailor-mcp?

resume-tailor-mcp is a production-ready Model Context Protocol (MCP) server with 3 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install mr-martinsosa/resume-tailor-mcp

# Or manual
git clone https://github.com/mr-martinsosa/resume-tailor-mcp.git
cd resume-tailor-mcp
```

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
