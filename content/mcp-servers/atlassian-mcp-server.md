# atlassian-mcp-server MCP Server

## What is atlassian-mcp-server?

atlassian-mcp-server is a production-ready Model Context Protocol (MCP) server with 1,035 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install atlassian/atlassian-mcp-server

# Or manual
git clone https://github.com/atlassian/atlassian-mcp-server.git
cd atlassian-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
