# minecraft-mcp-server MCP Server

## What is minecraft-mcp-server?

minecraft-mcp-server is a production-ready Model Context Protocol (MCP) server with 737 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

```bash
# Via Smithery (recommended)
```
