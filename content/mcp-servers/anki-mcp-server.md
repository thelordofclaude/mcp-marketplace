# anki-mcp-server MCP Server

## What is anki-mcp-server?

anki-mcp-server is a production-ready Model Context Protocol (MCP) server with 480 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install ankimcp/anki-mcp-server

# Or manual
git clone https://github.com/ankimcp/anki-mcp-server.git
cd anki-mcp-server
```

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
