# exa-mcp-server MCP Server

## What is exa-mcp-server?

exa-mcp-server is a production-ready Model Context Protocol (MCP) server with 4,981 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install exa-labs/exa-mcp-server

# Or manual
git clone https://github.com/exa-labs/exa-mcp-server.git
```

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
