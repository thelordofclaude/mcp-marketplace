# korean-law-mcp MCP Server

## What is korean-law-mcp?

korean-law-mcp is a production-ready Model Context Protocol (MCP) server with 2,559 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install chrisryugj/korean-law-mcp

# Or manual
git clone https://github.com/chrisryugj/korean-law-mcp.git
cd korean-law-mcp
```
