# docs-mcp-server MCP Server

## What is docs-mcp-server?

docs-mcp-server is a production-ready Model Context Protocol (MCP) server with 1,718 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install arabold/docs-mcp-server

# Or manual
git clone https://github.com/arabold/docs-mcp-server.git
cd docs-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
