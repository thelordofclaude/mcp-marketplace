# chrome-devtools-mcp MCP Server

## What is chrome-devtools-mcp?

chrome-devtools-mcp is a production-ready Model Context Protocol (MCP) server with 51,237 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install ChromeDevTools/chrome-devtools-mcp

# Or manual
git clone https://github.com/ChromeDevTools/chrome-devtools-mcp.git
cd chrome-devtools-mcp
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
