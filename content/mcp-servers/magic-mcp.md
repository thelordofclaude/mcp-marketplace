# magic-mcp MCP Server

## What is magic-mcp?

magic-mcp is a production-ready Model Context Protocol (MCP) server with 5,817 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install 21st-dev/magic-mcp

# Or manual
git clone https://github.com/21st-dev/magic-mcp.git
cd magic-mcp
```

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
