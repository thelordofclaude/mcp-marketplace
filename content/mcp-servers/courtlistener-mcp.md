# courtlistener-mcp MCP Server

## What is courtlistener-mcp?

courtlistener-mcp is a production-ready Model Context Protocol (MCP) server with 14 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install blakeox/courtlistener-mcp

# Or manual
git clone https://github.com/blakeox/courtlistener-mcp.git
cd courtlistener-mcp
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
