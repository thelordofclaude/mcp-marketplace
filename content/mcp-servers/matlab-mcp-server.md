# matlab-mcp-server MCP Server

## What is matlab-mcp-server?

matlab-mcp-server is a production-ready Model Context Protocol (MCP) server with 1,466 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install matlab/matlab-mcp-server

# Or manual
git clone https://github.com/matlab/matlab-mcp-server.git
cd matlab-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
