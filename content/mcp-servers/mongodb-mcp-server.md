# mongodb-mcp-server MCP Server

## What is mongodb-mcp-server?

mongodb-mcp-server is a production-ready Model Context Protocol (MCP) server with 1,128 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install mongodb-js/mongodb-mcp-server

# Or manual
git clone https://github.com/mongodb-js/mongodb-mcp-server.git
cd mongodb-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
