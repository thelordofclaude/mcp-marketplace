# think-mcp-server MCP Server

## What is think-mcp-server?

think-mcp-server is a production-ready Model Context Protocol (MCP) server with 25 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install marcopesani/think-mcp-server

# Or manual
git clone https://github.com/marcopesani/think-mcp-server.git
cd think-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
