# MCP-Bridge MCP Server

## What is MCP-Bridge?

MCP-Bridge is a production-ready Model Context Protocol (MCP) server with 929 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install SecretiveShell/MCP-Bridge

# Or manual
git clone https://github.com/SecretiveShell/MCP-Bridge.git
cd MCP-Bridge
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
