# line-bot-mcp-server MCP Server

## What is line-bot-mcp-server?

line-bot-mcp-server is a production-ready Model Context Protocol (MCP) server with 777 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install line/line-bot-mcp-server

# Or manual
git clone https://github.com/line/line-bot-mcp-server.git
cd line-bot-mcp-server
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
