# prest MCP Server

## What is prest?

prest is a production-ready Model Context Protocol (MCP) server with 4,615 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install prest/prest

# Or manual
git clone https://github.com/prest/prest.git
cd prest
```

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
