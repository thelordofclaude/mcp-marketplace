# skills-mcp MCP Server

## What is skills-mcp?

skills-mcp is a production-ready Model Context Protocol (MCP) server with 10 GitHub stars. It allows AI agents like Claude to perform real-world tasks through standardized tool calls.

## Installation

```bash
# Via Smithery (recommended)
npx -y @smithery/cli install gengirish/skills-mcp

# Or manual
git clone https://github.com/gengirish/skills-mcp.git
cd skills-mcp
```

## Compatibility

Compatible with: Claude Desktop, Claude Code, Cursor, Windsurf, Cline, and any MCP-compliant client.
